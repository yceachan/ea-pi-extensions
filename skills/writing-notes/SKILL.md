# writing-notes

本技能提供一套写作纲领，确保每篇笔记结构一致、渲染可靠、知识可追溯。


## 一、YAML Frontmatter 规范

为了对齐渲染器的渲染行为边界,约定Frontmatter 规范:

1. **文件第一行必须是 `---`**。禁止前导空行
2. **YAML 闭合 `---` 前留 1 个空行**，。
3. **YAML 块结束后留 1 个空行**，再开始正文。

### 模板

```markdown
---
title: <name>
tags: [tag1, tag2]
note_types : < document | Cognition , | Jotting>
created: yyyy-mm-dd
updated: yyyy-mm-dd
---

# H1 Title
context...
```

## 二、Top Level Insight

### 2.1 Abstract

在正文开头，用一段Abstract领衔全文，站在行业专家的视角用一段话阐述问题背景、中心话题等核心洞察，。

## 三、行文纪律

写作前先想清楚这篇笔记是**给谁看、什么时候看**的。

| 维度         | document                                           | Cognition                                                    | Jotting                                        |
| :----------- | :------------------------------------------------- | :----------------------------------------------------------- | ---------------------------------------------- |
| **目的导向** | **呈现、对齐、交付**：让用户快速获得共识性全貌     | **思考、内化、涌现**：促进深度理解。                         | **随手简记**                                   |
| **读者画像** | 读者已对该技术栈有了较好的认知，需要归档技术文档。 | 读者刚在AI的指导下接触这个领域，正在AI导学下细化深入，需要沉淀学习轨迹。 | 读者能够轻松上手这份知识，需要归档以速查备忘。 |
| **章节结构** | 强结构化                                           | 强调概念间的**自然递进**                                     | 聚焦于**How**                                  |
| **内容性**   | 对已知结论的结构化整理。                           | 对既定话题的导入，深化                                       | 简明扼要，只讲核心机制                         |

- 叙事具备逻辑，层级结构递进，系统化分析思考。

## 四、结构编排

- 标题，图例等结构化索引的地方，用简洁名词，不能用长句子。

- 充分使用md 排版能力辅助阐述:

```text
- 要点解读 ：使用无序列表
- 结构对比 ：使用表格 
- 前置说明 ： 使用`>` ，明确type 用相应alerts e.g.`> [!xxx]`。
- 资源引用
   ```
   > [!note]
   > **Ref:** [web source](url) | [local source]($cwd/path)
   ```
```

## 五、图例演示

**当笔记讨论一个具体且复杂的机制,架构，时序等元素，联动 Harness的可视化能力，进行图例剖析。**。

- 产物要求 : 结构紧凑，内容详实，视觉效果好。考虑读者视觉体验，md正文渲染器通常为半屏宽度。
- 剖析层次 : 在较高层次给出整体视角，并对具体小节里聚焦的复杂局部问题，进行深入层次的图例剖析。
- 编排流程 : 编排子代理完成，传达机制具体内容和期望的可视化解释方式，不要浪费主线上下文窗口于样式细节。
- 可选路径 : 
  - mermaid，嵌入于md正文，简单机制，排版不复杂时使用它。
  - image,使用`picgo upload --format json <path/to/iamge>`上传到用户图床，在md正文嵌入url，机制间互相作用复杂，需要精细排版时使用它。
