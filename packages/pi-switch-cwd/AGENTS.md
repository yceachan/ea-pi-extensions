## Agent skills

### Issue tracker

Issues and design records live as markdown files under `.agents/docs/<feature>/` in this repo (meta docs never live at the repo root or under `docs/`). See `.agents/docs/issue-tracker.md`. Example: `.agents/docs/cwd/` for the /cwd feature.

### Domain docs

Single-context: one domain glossary per feature at `.agents/docs/<feature>/context.md` (+ design records in the same directory). See `.agents/docs/domain.md`. Example: `.agents/docs/cwd/context.md`.
